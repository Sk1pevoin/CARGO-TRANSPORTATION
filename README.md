# 🚛 Система управления грузоперевозками

Веб-приложение для управления грузоперевозками с функционалом создания заявок, расчета стоимости перевозки, управления пользователями и административной панелью.


## 📝 Описание

Система управления грузоперевозками - это полнофункциональное веб-приложение, которое позволяет:

- Клиентам создавать заявки на перевозку грузов
- Рассчитывать стоимость перевозки с помощью калькулятора
- Управлять личным кабинетом и профилем
- Администраторам управлять заявками, пользователями и транспортом
- Отслеживать статистику и аналитику

## 🛠 Технологии

### Backend
- **Node.js** - среда выполнения
- **SQLite3** - база данных
### Frontend
- **HTML5** - разметка
- **CSS3** - стилизация
- **JavaScript (ES6+)** - клиентская логика

## 📦 Установка

1. **Клонируйте репозиторий** или скачайте проект

2. **Установите зависимости:**

```bash
cd JavaScript
npm install
```

Установятся следующие пакеты:
- `sqlite3` - база данных

## 🚀 Запуск

1. **Запустите сервер:**

```bash
cd JavaScript
node server.js
```

Сервер запустится на порту **3000** (или следующем доступном порту, если 3000 занят).

2. **Откройте браузер и перейдите по адресу:**

```
http://localhost:3000
```

3. **Проверка работы сервера:**

```
http://localhost:3000/api/health
```

## ⚙️ Функционал

### Для пользователей

- **Регистрация и авторизация** - создание аккаунта и вход в систему
- **Создание заявок** - подача заявок на перевозку груза с указанием:
  - Пункта отправления и назначения
  - Веса груза
  - Типа груза
  - Даты перевозки
- **Калькулятор стоимости** - расчет стоимости перевозки на основе:
  - Расстояния
  - Веса груза
  - Типа груза
- **Личный кабинет** - просмотр и управление:
  - Профилем пользователя
  - Своими заявками
  - Историей расчетов
- **Контакты** - отправка сообщений через форму обратной связи

### Для администраторов

- **Управление заявками** - просмотр, изменение статусов заявок
- **Управление пользователями** - просмотр списка пользователей
- **Управление транспортом** - добавление, удаление транспортных средств
- **Статистика** - просмотр аналитики:
  - Общее количество заявок
  - Новые заявки
  - Заявки в работе
  - Выполненные заявки
  - Количество пользователей
- **Распределение грузов** - назначение транспорта на заявки

## 🗄 База данных

### SQLite

База данных создается автоматически в файле `JavaScript/database.db` при первом запуске сервера.

#### Таблицы:

**client_auth** - Пользователи
- `id` - PRIMARY KEY
- `login` - UNIQUE, логин пользователя
- `password` - хешированный пароль
- `name` - имя пользователя
- `email` - email
- `phone` - телефон
- `role` - роль (user/admin)
- `created_at` - дата создания

**bid** - Заявки
- `id` - PRIMARY KEY
- `name` - название заявки
- `wherefrom` - пункт отправления
- `towhere` - пункт назначения
- `status` - статус (новая/в работе/выполнена)
- `user_id` - ID пользователя
- `weight` - вес груза
- `type` - тип груза
- `date` - дата перевозки
- `created_at` - дата создания

**contacts** - Контакты
- `id` - PRIMARY KEY
- `phone` - телефон
- `email` - email
- `name` - имя
- `subject` - тема
- `message` - сообщение
- `created_at` - дата создания

### IndexedDB

Используется для локального хранения данных в браузере:
- Пользователи
- Заявки
- Транспорт
- Расчеты
- Контакты


## 📝 Примечания

- Сервер автоматически создает базу данных при первом запуске
- Если порт 3000 занят, сервер попытается использовать следующий доступный порт
- База данных SQLite создается в папке `JavaScript/`

## 🐛 Решение проблем

### Порт уже используется
Сервер автоматически попытается использовать следующий доступный порт.

### Ошибки базы данных
Убедитесь, что у приложения есть права на запись в папку `JavaScript/` для создания файла `database.db`.
